description: Using TocaToca comfortably on your computer.
---

TocaToca runs directly in your web browser. No additional software or app installation is required.

## Open TocaToca

Go to [play.tocatoca.com](https://play.tocatoca.com).

If you are not already signed in, you will be automatically redirected to the login page.

## Advantages of Using a Computer

Using TocaToca on a computer provides more screen space for exploring the catalog and discovering music.

A larger display makes it easier to:

* browse collections
* compare recordings
* work with playlists
* explore artists, orchestras, and related recordings

## Recommended Browsers

TocaToca works with all modern browsers. For the best experience, we recommend:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox
* Safari

## Keep Your Browser Up to Date

We recommend using the latest version of your browser.

This ensures reliable playback, improved security, and the best possible performance while using TocaToca.
