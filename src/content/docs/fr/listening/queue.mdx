---
title: File d’attente
description: Gérer les enregistrements qui seront joués ensuite.
---

La file d’attente contient tous les enregistrements prévus pour la suite de l’écoute.

L’icône de file d’attente dans le lecteur indique aussi le nombre actuel d’enregistrements en attente.

## Ajouter des enregistrements à la file d’attente

Vous pouvez ajouter des enregistrements individuels ou des listes entières à la file d’attente.

Sélectionnez les enregistrements souhaités, puis choisissez **"Play Next"**.

Cela vous permet :

* d’ajouter des enregistrements individuels
* d’ajouter plusieurs enregistrements sélectionnés
* de placer des listes entières ou des résultats de recherche dans la file d’attente

![File d’attente](/images/manual/de-warteschlange.jpg)

## Modifier l’ordre

La file d’attente est lue dans l’ordre affiché à l’écran.

Vous pouvez déplacer des enregistrements à tout moment par glisser-déposer.

Vous décidez ainsi précisément quel enregistrement sera joué ensuite.

## Retirer des enregistrements

Les enregistrements dont vous n’avez plus besoin peuvent être retirés directement de la file d’attente.

Utilisez le **X** à côté de l’enregistrement concerné.

## Vider toute la file d’attente

Pour retirer tous les enregistrements de la file d’attente, utilisez l’icône de corbeille.

Vous pouvez ensuite créer une nouvelle file d’attente ou ajouter d’autres enregistrements.

## Quand la file d’attente est-elle utile ?

La file d’attente est idéale lorsque vous souhaitez écouter plusieurs enregistrements à la suite sans créer de playlist.

Contrairement à une playlist, la file d’attente n’existe que pour la session d’écoute en cours.
