---
title: Problèmes avec les navigateurs mobiles
description: Aide pour la lecture et la connexion sur smartphone et tablette.
---

Les navigateurs mobiles se comportent parfois différemment des navigateurs sur ordinateur. Cela peut avoir une influence sur les sessions de connexion, la lecture audio et la manière dont les données du navigateur sont conservées.

## Ma connexion n’est pas mémorisée

Les appareils mobiles modernes utilisent souvent des réglages stricts de confidentialité et de cookies.

Il peut donc arriver que l’on vous demande de vous connecter de nouveau, même si vous avez déjà utilisé TocaToca auparavant.

## Se connecter de nouveau

Ouvrez [auth.tocatoca.com](https://auth.tocatoca.com) et connectez-vous de nouveau avec votre adresse e-mail et votre mot de passe.

Après une connexion réussie, cliquez sur **"Open Player"** pour revenir à TocaToca.

## La lecture ne démarre pas

Sur smartphone et tablette, la lecture audio doit toujours être déclenchée par une action directe de l’utilisateur.

Touchez l’enregistrement souhaité ou le bouton de lecture pour commencer l’écoute.

## La page ne répond pas

Rechargez la page et réessayez.

Si le problème persiste, connectez-vous de nouveau via [auth.tocatoca.com](https://auth.tocatoca.com), puis rouvrez le lecteur.

## Aide supplémentaire

Si le problème continue, veuillez contacter <a href="mailto:support@tocatoca.com">[support@tocatoca.com](mailto:support@tocatoca.com)</a>.

Les informations suivantes nous aideront à examiner le problème :

* type d’appareil (iPhone, iPad, appareil Android, etc.)
* navigateur utilisé
* description du problème
* détails sur le moment où le problème se produit

Plus vous fournissez d’informations, plus il nous sera facile d’identifier la cause.
