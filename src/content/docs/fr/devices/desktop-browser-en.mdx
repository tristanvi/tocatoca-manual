title: Navigateur sur ordinateur
description: Utiliser TocaToca confortablement sur votre ordinateur.
---

TocaToca fonctionne directement dans votre navigateur web. Aucun logiciel supplémentaire ni aucune installation d’application n’est nécessaire.

## Ouvrir TocaToca

Allez sur [play.tocatoca.com](https://play.tocatoca.com).

Si vous n’êtes pas déjà connecté, vous serez automatiquement redirigé vers la page de connexion.

## Avantages de l’utilisation sur ordinateur

Utiliser TocaToca sur un ordinateur offre plus d’espace à l’écran pour explorer le catalogue et découvrir de la musique.

Un écran plus grand permet plus facilement de :

* parcourir les collections
* comparer les enregistrements
* travailler avec des playlists
* explorer les artistes, les orchestres et les enregistrements associés

## Navigateurs recommandés

TocaToca fonctionne avec tous les navigateurs modernes. Pour une meilleure expérience, nous recommandons :

* Google Chrome
* Microsoft Edge
* Mozilla Firefox
* Safari

## Garder votre navigateur à jour

Nous recommandons d’utiliser la version la plus récente de votre navigateur.

Cela garantit une lecture fiable, une meilleure sécurité et les meilleures performances possibles lors de l’utilisation de TocaToca.
