---

Un compte personnel est nécessaire pour utiliser TocaToca. L’accès invité n’est actuellement pas disponible.

## Inscription

Ouvrez [auth.tocatoca.com](https://auth.tocatoca.com) et suivez les étapes pour créer votre compte.

![Créer un compte](/images/manual/de-konto-erstellen01.jpg)

![Créer un compte](/images/manual/de-konto-erstellen02.jpg)

## Choisir le bon abonnement

Deux formules d’abonnement sont disponibles pour une utilisation personnelle :

* 10 € par mois
* 100 € par an

Si vous souhaitez utiliser TocaToca pour une école de danse, un club, une association ou une organisation similaire, un abonnement organisateur est disponible pour 200 € par an.

Choisissez l’abonnement qui correspond le mieux à vos besoins.

![Choisir un abonnement](/images/manual/abonnement.jpg)

### Remarque pour les DJs professionnels

TocaToca est destiné à l’écoute personnelle ainsi qu’à l’utilisation par des écoles de danse, des clubs et des organisateurs d’événements.

Les DJs de tango professionnels qui se produisent lors d’événements rémunérés ont besoin de droits d’utilisation distincts. Ces droits ne sont pas inclus dans l’abonnement standard.

## Paiement via Stripe

Après avoir choisi votre abonnement, vous serez automatiquement redirigé vers Stripe. Stripe assure le traitement sécurisé des paiements pour TocaToca.

Veuillez saisir les informations demandées, y compris vos données de paiement.

![Stripe](/images/manual/stripe.jpg)

Si vous annulez votre abonnement dans les trois jours suivant l’inscription, aucun montant ne sera prélevé.

## Activation

Une fois l’inscription et le paiement terminés avec succès, votre compte est activé automatiquement.

Vous pouvez ensuite vous connecter à TocaToca et commencer l’écoute immédiatement.

Vous pouvez vérifier le [statut de votre abonnement](/fr/account-access/subscription-status/) ou lire les recommandations sur l’[utilisation responsable](/fr/account-access/responsible-use/) de votre compte.
