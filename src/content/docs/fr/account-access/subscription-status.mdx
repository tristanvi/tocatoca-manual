Le statut de votre abonnement indique si votre accès à TocaToca est actif.

## Vérifier votre statut

Connectez-vous sur [auth.tocatoca.com](https://auth.tocatoca.com) et ouvrez la section **Subscription**.

![Statut de l’abonnement](/images/manual/abonnementstatus.jpg)

## Si votre abonnement est actif

Ouvrez [play.tocatoca.com](https://play.tocatoca.com).

Avec un abonnement actif, vous avez accès à l’ensemble du catalogue disponible.

Vous pouvez aussi utiliser le bouton **« Open Player »** pour accéder directement au lecteur TocaToca.

## Si votre abonnement n’est pas actif

Suivez les indications dans votre espace de compte pour terminer le processus d’activation.

Si votre accès n’a toujours pas été activé, contactez le support à l’adresse <a href="mailto:support@tocatoca.com">[support@tocatoca.com](mailto:support@tocatoca.com)</a>.
