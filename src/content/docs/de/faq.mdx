## Kann ich Musik herunterladen?

Nein. TocaToca ist für Streaming gedacht. Die Musik wird direkt im Browser abgespielt.

## Warum führt ein Künstlerlink zu einer Songliste?

Damit Sie sofort hörbare Aufnahmen finden. Ein Künstlerlink zeigt Songs, die mit diesem Namen verbunden sind.

## Wo melde ich mich an?

Der Login läuft über [auth.tocatoca.com](https://auth.tocatoca.com). Die Musik-App ist unter [play.tocatoca.com](https://play.tocatoca.com) erreichbar.

## Kann ich Favoriten speichern?

Ja. Markieren Sie Songs als Favoriten, um sie später schneller wiederzufinden.
Dies passiert in dem Sie das Herz drücken.

## Kann ich eigene Playlists anlegen?

Ja. Playlists sind für eigene Zusammenstellungen gedacht.

## Wie füge ich einen Song einer Playlist hinzu?
Sie finden im Header einer Songliste mehrere Symbole. Je nach Gerät auf dem Sie hören, sind diese Symbole mit Text versehen oder nicht.
Diese Symbole tauchen auf, wenn Sie Songs markieren.

![Header with symbols when marking a song](/images/manual/symbols-header-list.jpg)

## Kann ich mehrere Songs auf einmal einer Playlist hinzufügen.
Ja. Markieren Sie entweder alle Songs durch Klick auf das Quadrat links oben im Header der Liste oder klicken Sie selektiv das Quadrat des jeweiligen Songs.

## Kann ich einen Song oder eine Songauswahl mehreren Playlists gleichzeitig zuordnen.
Ja. Markieren Sie alle Playlists, denen die Songs zugeordnet werden sollen.
