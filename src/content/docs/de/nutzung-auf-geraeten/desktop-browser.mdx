------------------------------------------------

TocaToca funktioniert direkt im Browser. Eine zusätzliche Software oder App ist nicht erforderlich.

## TocaToca öffnen

Öffnen Sie [play.tocatoca.com](https://play.tocatoca.com). Falls Sie noch nicht angemeldet sind, werden Sie automatisch zur Anmeldung weitergeleitet.

## Vorteile am Computer

Die Nutzung am Computer bietet besonders viel Platz für die Musiksuche und das Stöbern im Katalog.

Ein großer Bildschirm erleichtert:

* das Durchsuchen von Sammlungen
* das Vergleichen von Aufnahmen
* das Arbeiten mit Playlists
* das Entdecken von Künstlern, Orchestern und verwandten Aufnahmen

## Empfohlene Browser

TocaToca funktioniert mit allen aktuellen Browsern. Für die beste Erfahrung empfehlen wir:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox
* Safari

## Browser aktuell halten

Verwenden Sie möglichst die aktuelle Version Ihres Browsers. So profitieren Sie von einer zuverlässigen Wiedergabe sowie den neuesten Sicherheits- und Leistungsverbesserungen.
