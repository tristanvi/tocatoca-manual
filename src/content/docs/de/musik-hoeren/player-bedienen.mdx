Der Player steuert die laufende Musik. Er bleibt sichtbar, während Sie weiter in TocaToca suchen oder stöbern.

## Start und Pause

Mit der Play-Taste starten Sie die Musik. Mit Pause halten Sie sie an.

![Player Desktop] (/images/manual/player-desktop-001.jpg)

Auf Ihrem Mobilgerät sieht das so aus.

![Player Mobile] (/images/manual/player-mobile-001.jpg)

Sie gelangen dorthin in dem Sie das Schellacksymbol anklicken, welches Sie an jede Stelle auf Ihrem Mobilgerät verschieben können.

![Player Mobile Symbol] (/images/manual/player-mobile-symbol-001.jpg)

## Vor und zurück

Mit den Sprungtasten wechseln Sie zum nächsten oder vorherigen Titel in der aktuellen Liste oder Warteschlange.

## Lautstärke

Die Lautstärke kann im Player, im Browser oder direkt am Gerät geregelt werden.
