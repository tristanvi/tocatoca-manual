---

title: Favoriten
description: Aufnahmen speichern und schnell wiederfinden.
----------------------------------------------------------

Mit Favoriten können Sie Aufnahmen markieren, die Sie später schnell wiederfinden möchten.

## Eine Aufnahme als Favorit markieren

Klicken oder tippen Sie auf das Herzsymbol neben einer Aufnahme oder direkt im Player.

![Favoritenliste mit markierten Aufnahmen](/images/manual/favorites-001.jpg)

*Das Herzsymbol markiert eine Aufnahme als Favorit. Alle gespeicherten Favoriten finden Sie gesammelt an einem Ort.*

## Favoriten anzeigen

Wählen Sie im Menü den Bereich **Favoriten**.

Dort sehen Sie alle Aufnahmen, die Sie zuvor mit einem Herz markiert haben.

Favoriten eignen sich besonders, um interessante Aufnahmen schnell wiederzufinden oder persönliche Entdeckungen für später zu speichern.

## Einen Favoriten entfernen

Klicken oder tippen Sie erneut auf das Herzsymbol, um die Aufnahme aus Ihren Favoriten zu entfernen.

Die Aufnahme bleibt selbstverständlich weiterhin im TocaToca-Katalog verfügbar.
