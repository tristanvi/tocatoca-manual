Die Warteschlange zeigt, welche Songs als Nachstes laufen.

## Titel hinzufügen

Fügen Sie Songs aus einer Songliste zur Warteschlange hinzu, wenn Sie sie später hören möchten.

:::tip[TODO Screenshot]
Screenshot der Warteschlange einfügen: `public/images/manual/de-warteschlange.png`.
:::

## Reihenfolge verstehen

TocaToca spielt die Titel in der angezeigten Reihenfolge ab. Wenn Sie eine neue Liste starten, kann sich die Warteschlange ändern.

## Warteschlange leeren

Wenn die Liste zu lang wird, starten Sie einfach eine neue Auswahl oder entfernen Sie einzelne Titel, sofern die Aktion angezeigt wird.
