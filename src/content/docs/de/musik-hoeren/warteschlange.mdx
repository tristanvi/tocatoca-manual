title: Warteschlange
description: Verwalten Sie die Aufnahmen, die als Nächstes abgespielt werden.
-----------------------------------------------------------------------------

Die Warteschlange enthält alle Aufnahmen, die als Nächstes abgespielt werden.

Neben dem Warteschlangen-Symbol im Player wird die aktuelle Anzahl der enthaltenen Aufnahmen angezeigt.

## Aufnahmen zur Warteschlange hinzufügen

Sie können einzelne Aufnahmen oder ganze Listen zur Warteschlange hinzufügen.

Markieren Sie dazu die gewünschten Aufnahmen und wählen Sie anschließend **„Als Nächstes abspielen“**.

Auf diese Weise können Sie:

* einzelne Aufnahmen hinzufügen
* mehrere ausgewählte Aufnahmen übernehmen
* komplette Listen oder Suchergebnisse in die Warteschlange stellen

![Warteschlange](/images/manual/de-warteschlange.jpg)

## Reihenfolge ändern

Die Warteschlange wird in der angezeigten Reihenfolge abgespielt.

Sie können einzelne Aufnahmen jederzeit per Drag & Drop an eine andere Position verschieben.

So bestimmen Sie selbst, welche Aufnahme als Nächstes gespielt wird.

## Aufnahmen entfernen

Nicht mehr benötigte Aufnahmen können direkt aus der Warteschlange entfernt werden.

Verwenden Sie dazu das **X** neben der jeweiligen Aufnahme.

## Warteschlange vollständig leeren

Wenn Sie die gesamte Warteschlange löschen möchten, verwenden Sie das Papierkorb-Symbol.

Anschließend können Sie eine neue Reihenfolge zusammenstellen oder andere Aufnahmen hinzufügen.

## Wann ist die Warteschlange hilfreich?

Die Warteschlange eignet sich besonders, wenn Sie spontan mehrere Aufnahmen hintereinander hören möchten, ohne dafür eine Playlist anzulegen.

Im Gegensatz zu einer Playlist bleibt die Warteschlange nur für die aktuelle Hörsitzung bestehen.
