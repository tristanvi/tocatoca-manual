---
title: Warteschlange
description: Was als Nächstes abgespielt wird.
---

Die Warteschlange zeigt, welche Titel als Nächstes abgespielt werden.
Neben dem Symbol rechts in der Abspielleiste sehen Sie auch eine Nummer, die Ihnen die Zahl der vorhandenen Titel der Warteschlange anzeigt.

## Titel hinzufügen

Fügen Sie Songs aus einer Songliste zur Warteschlange hinzu, wenn Sie sie später hören möchten. 
Dazu verwenden Sie den Button "Als nächstes abspielen" in der Headerleiste. Sie können eine ganze Liste oder selektive Titel damit zur Warteschlange hinzufügen.

![Warteschlange](/images/manual/de-warteschlange.jpg)

## Reihenfolge verstehen

TocaToca spielt die Titel in der angezeigten Reihenfolge ab. Sie können einzelne Titel durch Ziehen auf eine andere Position ziehen.

## Warteschlange leeren

Wenn die Liste zu lang wird, drücken Sie das Papierkorbsymbol oder entfernen Sie einzelne Titel in der Warteschlange durch Klicken auf das X neben dem Titel.
