Die Warteschlange zeigt, welche Songs als Nachstes laufen.

## Titel hinzufugen

Fugen Sie Songs aus einer Songliste zur Warteschlange hinzu, wenn Sie sie spater horen mochten.

:::tip[TODO Screenshot]
Screenshot der Warteschlange einfugen: `public/images/manual/de-warteschlange.png`.
:::

## Reihenfolge verstehen

TocaToca spielt die Titel in der angezeigten Reihenfolge ab. Wenn Sie eine neue Liste starten, kann sich die Warteschlange andern.

## Warteschlange leeren

Wenn die Liste zu lang wird, starten Sie einfach eine neue Auswahl oder entfernen Sie einzelne Titel, sofern die Aktion angezeigt wird.
