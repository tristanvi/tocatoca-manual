TocaToca kann den Zugang per Passwort, Magic Link oder einer anderen Konto-Bestatigung ermoglichen.

## Magic Link verwenden

Ein Magic Link ist ein Login-Link, der per E-Mail gesendet wird. Offnen Sie ihn moglichst im selben Browser, in dem Sie TocaToca nutzen.

Screenshot einer Magic-Link-E-Mail oder neutraler Platzhalter einfugen: `public/images/manual/de-magic-link-email.png`.
:::

## Passwort verwenden

Wenn Ihr Konto ein Passwort nutzt, geben Sie es auf der Login-Seite ein. Verwenden Sie die Zurucksetzen-Funktion, wenn Sie es vergessen haben.

## Zugang sicher halten

Teilen Sie Login-Links oder Zugangsdaten nicht mit anderen Personen.
