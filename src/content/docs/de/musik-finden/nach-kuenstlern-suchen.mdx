Künstlerseiten helfen Ihnen, Aufnahmen zu finden, die mit einer Person, einem Orchester oder einer Gruppe verbunden sind.

## Künstler finden

Klicken Sie links im Menü auf <i>Artists</i>.
Es öffnet sich eine Liste

![Artist Liste](/images/manual/artist-list-001.jpg)

Tippen Sie im Suchbereich ihren Suchbegriff ein

![Artist Liste](/images/manual/artist-list-002.jpg)

## Ergebnis einer Suche als Playlist speichern.

Wenn Sie auf den Namen des Suchergebnisses klicken, bekommen Sie die Liste angezeigt, in unserem Beispiel alle verfügbaren Songs mit Alberto Podestá.

![Artist Liste Filter] (/images/manual/artist-list-filter-001.jpg)

Markieren Sie alle Songs in der Liste, durch Klicken auf das Quadrat neben Titel.
Sie sehen alle Songs markiert.
Danach klicken Sie auf das Symbol "Zu einer Wiedergabeliste hinzufügen".
Wählen Sie eine bestehende aus oder legen Sie eine neue an. Wenn Sie eine neue anlegen, drücken Sie nach der Eingabe ENTER.

![Artist Liste Filter] (/images/manual/artist-list-filter-002.jpg)
![Artist Liste Filter] (/images/manual/artist-list-filter-003.jpg)


## Weitere Suchmöglichkeiten

Klicken Sie wie folgt um andere Rollen nach denen Sie suchen wollen auszuwählen.

![Artist Liste](/images/manual/artist-list-003.jpg)

Danach fahren Sie gewohnt fort.

## Historische Schreibweisen

Bei älteren Aufnahmen können Namen unterschiedlich geschrieben sein. Probieren Sie kurze Suchbegriffe, wenn ein vollständiger Name keine Treffer liefert.
