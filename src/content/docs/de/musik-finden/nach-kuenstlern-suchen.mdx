Über die Artists-Ansicht können Sie gezielt nach Künstlern, Orchestern und anderen Mitwirkenden suchen.

## Künstler suchen

Klicken Sie im Menü auf **Artists**.

Es öffnet sich die Übersicht aller verfügbaren Künstler.

![Artist Liste](/images/manual/artist-list-001.jpg)

Geben Sie anschließend Ihren Suchbegriff in das Suchfeld ein.

![Artist Liste](/images/manual/artist-list-002.jpg)

Die Liste wird während der Eingabe automatisch gefiltert.

## Alle Aufnahmen eines Künstlers anzeigen

Klicken Sie auf den Namen eines Suchergebnisses.

Im folgenden Beispiel werden alle verfügbaren Aufnahmen mit **Alberto Podestá** angezeigt.

![Artist Liste Filter](/images/manual/artist-list-filter-001.jpg)

So erhalten Sie sofort Zugriff auf alle passenden Aufnahmen im Katalog.

## Suchergebnis als Playlist speichern

Sie können die angezeigten Aufnahmen direkt einer Playlist hinzufügen.

Markieren Sie dazu die gewünschten Aufnahmen oder wählen Sie alle Aufnahmen der Liste aus.

Klicken Sie anschließend auf das Symbol **„Zu Playlist hinzufügen“**.

Wählen Sie eine bestehende Playlist aus oder erstellen Sie eine neue.

Beim Anlegen einer neuen Playlist bestätigen Sie den Namen mit der Eingabetaste.

![Artist Liste Filter](/images/manual/artist-list-filter-002.jpg)

![Artist Liste Filter](/images/manual/artist-list-filter-003.jpg)

## Nach anderen Rollen suchen

Die Artists-Ansicht unterstützt verschiedene Rollen und Kategorien.

Über die Auswahl oberhalb der Liste können Sie festlegen, welche Art von Mitwirkenden angezeigt werden soll.

![Artist Liste](/images/manual/artist-list-003.jpg)

Anschließend können Sie wie gewohnt nach Namen suchen und die Ergebnisse filtern.

## Historische Schreibweisen

Bei historischen Aufnahmen kommen unterschiedliche Schreibweisen von Namen vor.

Wenn eine Suche keine Treffer liefert, versuchen Sie:

* nur den Nachnamen
* nur einen Teil des Namens
* alternative Schreibweisen

Oft führt bereits ein kürzerer Suchbegriff zu den gewünschten Ergebnissen.
