Die Suche ist der schnellste Einstieg, wenn Sie schon wissen, wonach Sie suchen.

## Suchfeld offnen

Klicken Sie in das Suchfeld und geben Sie einen Begriff ein. Das kann ein Kunstlername, ein Songtitel, ein Orchester, ein Label oder ein anderer Hinweis sein.

## Ergebnisse ansehen

Die Ergebnisse konnen Songs, Kunstler, Alben oder Sammlungen enthalten. Offnen Sie den passenden Treffer und starten Sie die Musik von dort.

## Besser suchen

Wenn Sie zu viele Treffer sehen, verwenden Sie einen genaueren Begriff. Wenn Sie zu wenige Treffer sehen, versuchen Sie eine kurzere Schreibweise oder nur einen Teil des Namens.
