Die Suche ist der schnellste Einstieg, wenn Sie schon wissen, wonach Sie suchen.

## Suchfeld öffnen

Klicken Sie in das Suchfeld und geben Sie einen Begriff ein. Das kann ein Künstlername, ein Songtitel, ein Orchester, ein Komponist, ein Texter oder ein anderer Hinweis sein.

![Geöffnete Sammlung mit Songliste](/images/manual/de-suche.jpg)

## Ergebnisse ansehen

Die Ergebnisse können Songs, Künstler, Alben oder Sammlungen enthalten. Öffnen Sie den passenden Treffer und starten Sie die Musik von dort.
Sie können die Trefferauswahl auch sortieren, durch Klick auf den Spaltenheader, zB Albuminterpret, Jahr, Genre.

## Besser suchen

Wenn Sie zu viele Treffer sehen, verwenden Sie einen genaueren Begriff. Wenn Sie zu wenige Treffer sehen, versuchen Sie eine kürzere Schreibweise oder nur einen Teil des Namens.

Im Standardsuchbereich können Sie immer nur einen Suchbegriff eingeben, wenn Sie jedoch Filter hinzufügen können Sie komplexere Suchen starten.
Wenn Sie zB alle Titel finden bei denen Alberto Podestá oder Roberto Rufino singen und die von Carlos Di Sarli komponiert wurden, müssen Sie mit Filtern arbeiten.
Die erweiterten Filteroptionen stehen Ihnen nur im Bereich Titel zur Verfügung.
Rechts oben sehen Sie einen Button "FILTER HINZUFÜGEN" und dann wählen Sie den gewünschten aus.
