Die Suche ist der schnellste Einstieg, wenn Sie schon wissen, wonach Sie suchen.

## Suchfeld öffnen

Klicken Sie in das Suchfeld und geben Sie einen Begriff ein. Das kann ein Künstlername, ein Songtitel, ein Orchester, ein Label oder ein anderer Hinweis sein.

## Ergebnisse ansehen

Die Ergebnisse können Songs, Künstler, Alben oder Sammlungen enthalten. Öffnen Sie den passenden Treffer und starten Sie die Musik von dort.

## Besser suchen

Wenn Sie zu viele Treffer sehen, verwenden Sie einen genaueren Begriff. Wenn Sie zu wenige Treffer sehen, versuchen Sie eine kürzere Schreibweise oder nur einen Teil des Namens.
