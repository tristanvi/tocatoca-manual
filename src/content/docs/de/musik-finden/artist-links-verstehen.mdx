---

title: Artist-Links verstehen
description: Warum Artist-Links in TocaToca direkt zu passenden Aufnahmen führen.
---------------------------------------------------------------------------------

In TocaToca sollen Artist-Links möglichst schnell zur Musik führen. Deshalb öffnet ein Klick auf einen Artist-Link keine technische Detailseite, sondern direkt eine Liste passender Aufnahmen.

## Was passiert beim Klick?

Wenn Sie auf einen Künstlernamen klicken, zeigt TocaToca alle verfügbaren Aufnahmen an, die mit dieser Person oder diesem Ensemble verbunden sind.

Das kann beispielsweise sein:

* ein Sänger oder eine Sängerin
* ein Orchester
* ein Instrumentalist
* ein Komponist
* ein Texter
* eine andere beteiligte Person

![Songliste nach Klick auf einen Artist-Link](/images/manual/artist-001.jpg)

*Der ausgewählte Name erscheint als aktiver Filter. Angezeigt werden alle Aufnahmen, die mit diesem Künstler verbunden sind.*

![Songliste nach Klick auf einen Orchester-Link](/images/manual/artist-002.jpg)

*Auch Orchester und andere Mitwirkende führen zu einer passenden Liste von Aufnahmen. So lassen sich weitere Titel aus demselben musikalischen Umfeld entdecken.*

## Warum gibt es keine Detailseite?

TocaToca wurde für das Hören und Entdecken von Musik entwickelt. Statt einer technischen Informationsseite gelangen Sie direkt zu den Aufnahmen, die Sie sofort abspielen können.

## Ideal zum Entdecken

Artist-Links sind besonders hilfreich, wenn Sie Zusammenhänge innerhalb der Tango-Geschichte erkunden möchten.

Mit wenigen Klicks finden Sie:

* weitere Aufnahmen desselben Sängers
* andere Titel eines Orchesters
* Aufnahmen mit denselben Musikern
* verwandte Künstler und Ensembles

So wird aus einer einzelnen Aufnahme oft der Ausgangspunkt für eine ganze musikalische Entdeckungsreise.
