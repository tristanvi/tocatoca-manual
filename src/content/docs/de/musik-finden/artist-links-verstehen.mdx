---
title: Artist-Links verstehen
description: Warum Künstlerlinks in TocaToca zu Songlisten führen.
---

In TocaToca sollen Künstlerlinks schnell zu Musik führen. Darum öffnet ein vorhandener Artist-Link eine Songliste mit passenden Aufnahmen.

## Was passiert beim Klick?

Wenn Sie auf einen Künstlernamen klicken, zeigt TocaToca verfügbare Songs, die mit diesem Namen verbunden sind. Das kann die Hauptperson, ein Orchester, eine Stimme oder eine andere Mitwirkung sein.

![Songliste nach Klick auf einen Artist-Link](/images/manual/artist-001.jpg)

*Der gewählte Name erscheint als Filter. Die Liste zeigt dann Aufnahmen, die mit diesem Künstler verbunden sind.*

![Songliste nach Klick auf einen Orchester-Link](/images/manual/artist-002.jpg)

*Auch Orchester oder andere Mitwirkende können zu einer passenden Songliste führen. So finden Sie schnell weitere Aufnahmen aus demselben Umfeld.*

## Warum keine technische Detailseite?

TocaToca ist für einfaches Hören gebaut. Statt einer komplizierten Verwaltungsseite sehen Sie direkt Musik, die Sie abspielen können.

## Gut zum Stöbern

Artist-Links sind besonders hilfreich, wenn Sie nach historischen Zusammenhangen suchen: gleiche Musiker, Orchester, Sangerinnen, Sanger oder andere Beteiligte.
