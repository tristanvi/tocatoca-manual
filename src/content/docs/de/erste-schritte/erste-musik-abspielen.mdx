Mit TocaToca können Sie historische Aufnahmen direkt im Browser hören. Sie laden keine Dateien herunter, sondern streamen die Musik. Öffnen Sie die App, melden Sie sich an und starten Sie einen Titel aus einer Sammlung oder Songliste.

Diese Seite führt Sie Schritt für Schritt bis zur ersten Wiedergabe.

## Voraussetzungen

Sie brauchen:

- ein TocaToca-Konto
- einen aktiven Zugang oder ein aktives Abonnement
- einen aktuellen Browser
- eine stabile Internetverbindung

TocaToca ist für Streaming gemacht. Die Musik wird beim Hören übertragen und bleibt nicht als Datei auf Ihrem Gerät.

## Einloggen

Öffnen Sie [play.tocatoca.com](https://play.tocatoca.com). Wenn Sie noch nicht angemeldet sind, werden Sie zum Login weitergeleitet.

Der Zugang wird über [auth.tocatoca.com](https://auth.tocatoca.com) verwaltet. Geben Sie dort Ihre E-Mail-Adresse ein und folgen Sie den angezeigten Schritten.

![Login-Bildschirm von TocaToca](/images/manual/login-001.jpg)

*Der Login-Bildschirm fragt nach Ihrer E-Mail-Adresse und Ihrem Passwort. Von hier aus können Sie auch ein neues Konto erstellen oder Hilfe beim Zugang anfordern.*

Wenn Sie einen Magic Link per E-Mail erhalten, öffnen Sie den Link am besten im selben Browser, in dem Sie TocaToca verwenden möchten.

## Eine Sammlung öffnen

Nach dem Login sehen Sie die Musikbibliothek von TocaToca. Sie können über die Startseite, die Suche oder die Navigation eine Sammlung öffnen.

In der App kann an manchen Stellen noch "Album" stehen. Im Handbuch sprechen wir von Sammlungen, weil es um zusammengehörige historische Aufnahmen geht.

![Startseite mit Sammlungen in TocaToca](/images/manual/home-001.jpg)

*Nach dem Einloggen sehen Sie die verfügbaren Sammlungen. Die Navigation links führt zu Sammlungen, Künstlern, Songlisten, Favoriten und Playlists.*

Klicken Sie auf eine Sammlung, um die enthaltenen Titel zu sehen.

![Geöffnete Sammlung mit Songliste](/images/manual/collection-001.jpg)

*Eine Sammlung zeigt Cover, Titelinformationen und die enthaltenen Aufnahmen. Mit Play starten Sie die Sammlung, oder Sie wählen einen einzelnen Titel aus der Liste.*

## Einen Titel starten

In einer Sammlung sehen Sie eine Liste mit Titeln. Klicken Sie auf einen Titel oder auf die Play-Taste, um die Wiedergabe zu starten.

Der Player erscheint unten in der App. Dort sehen Sie, was gerade läuft.

## Künstler-Links verwenden

Viele Titel enthalten Namen von Künstlerinnen, Künstlern, Orchestern oder anderen Mitwirkenden. Wenn ein Name als Link angezeigt wird, können Sie ihn anklicken.

TocaToca öffnet dann eine nützliche Songliste mit verfügbaren Aufnahmen, die mit diesem Namen verbunden sind. So entdecken Sie schnell weitere Titel von oder mit diesem Künstler.

![Songliste nach Klick auf einen Künstler-Link](/images/manual/artist-001.jpg)

*Nach dem Klick auf einen Künstler-Link zeigt TocaToca eine gefilterte Songliste mit verfügbaren Aufnahmen, die mit diesem Namen verbunden sind.*

:::note
Künstler-Links sind zum Stöbern gedacht. Sie führen direkt zu hörbarer Musik und nicht zu einer komplizierten Detailansicht.
:::

## Player bedienen

Mit dem Player steuern Sie die laufende Musik.

- Play startet die Wiedergabe.
- Pause hält die Wiedergabe an.
- Vor und Zurück wechseln zum nächsten oder vorherigen Titel.
- Die Lautstärke regeln Sie im Player, im Browser oder am Gerät.

Sie können während der Wiedergabe weiter in TocaToca suchen, andere Sammlungen öffnen oder neue Titel ansehen. Die Musik läuft weiter, solange der Browser und die Verbindung aktiv bleiben.

![Player am unteren Rand der App](/images/manual/player-desktop-001.jpg)

*Der Player bleibt unten sichtbar. Dort sehen Sie den laufenden Titel, die Fortschrittsanzeige, Play/Pause, Vor, Zurück, Favorit, Lautstärke und weitere Wiedergabeoptionen.*

## Wenn nichts abgespielt wird

Prüfen Sie zuerst diese Punkte:

- Ist Ihr Gerät laut genug eingestellt?
- Ist der Browser-Tab stummgeschaltet?
- Sind Sie noch eingeloggt?
- Ist Ihr Zugang aktiv?
- Funktioniert Ihre Internetverbindung?

Laden Sie die Seite einmal neu und starten Sie den Titel erneut.

:::caution
Auf iPhone, iPad und Android muss die Wiedergabe oft durch ein direktes Tippen auf Play gestartet werden. Das ist ein normales Verhalten mobiler Browser.
:::

Wenn weiterhin nichts zu hören ist, lesen Sie die Hinweise unter [Kein Ton](/de/fehlerbehebung/kein-ton/) oder [Musik startet nicht](/de/fehlerbehebung/musik-startet-nicht/).
