---

title: Kein Ton
description: Erste Hilfe, wenn keine Wiedergabe zu hören ist.
-------------------------------------------------------------

Wenn die Wiedergabe läuft, aber kein Ton zu hören ist, lassen sich die meisten Probleme mit wenigen Schritten beheben.

## Lautstärke prüfen

Prüfen Sie die Lautstärke:

* im TocaToca-Player
* im Browser
* auf Ihrem Computer, Tablet oder Smartphone

![Kein Ton](/images/manual/no-sound-volume.jpg)

## Eine andere Aufnahme testen

Starten Sie eine andere Aufnahme. So können Sie feststellen, ob das Problem nur bei einer bestimmten Aufnahme auftritt.

## Seite neu laden

Laden Sie die Seite neu und starten Sie die Wiedergabe erneut.

## Soundausgabe überprüfen

Vergewissern Sie sich, dass Ihr Gerät die richtige Soundausgabe verwendet.

Besonders bei Computern kann es vorkommen, dass der Ton an eine andere Audioquelle gesendet wird, beispielsweise:

* Bluetooth-Kopfhörer
* externe Lautsprecher
* AirPlay-Geräte
* HDMI-Monitore oder Fernseher

Wählen Sie gegebenenfalls die gewünschte Soundausgabe in den Audioeinstellungen Ihres Geräts aus.

## Wenn weiterhin kein Ton zu hören ist

Melden Sie sich einmal ab und wieder an oder starten Sie den Browser neu.

Sollte das Problem weiterhin bestehen, wenden Sie sich bitte an <a href="mailto:support@tocatoca.com">[support@tocatoca.com](mailto:support@tocatoca.com)</a>.
