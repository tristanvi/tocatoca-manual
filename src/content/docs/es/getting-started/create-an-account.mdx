Para usar TocaToca se necesita una cuenta personal. Actualmente no hay acceso como invitado.

## Registro

Abra [auth.tocatoca.com](https://auth.tocatoca.com) y siga los pasos para crear su cuenta.

![Crear cuenta](/images/manual/de-konto-erstellen01.jpg)

![Crear cuenta](/images/manual/de-konto-erstellen02.jpg)

## Elegir la suscripción adecuada

Hay dos opciones de suscripción para uso personal:

* 10 € al mes
* 100 € al año

Si desea usar TocaToca para una escuela de baile, un club, una asociación o una organización similar, está disponible una suscripción para organizadores por 200 € al año.

Elija la suscripción que mejor se adapte a sus necesidades.

![Elegir suscripción](/images/manual/abonnement.jpg)

### Nota para DJs profesionales

TocaToca está pensado para la escucha personal y también para el uso por escuelas de baile, clubes y organizadores de eventos.

Los DJs profesionales de tango que actúan en eventos de pago necesitan derechos de uso separados. Estos derechos no están incluidos en la suscripción estándar.

## Pago mediante Stripe

Después de seleccionar su suscripción, se le redirigirá automáticamente a Stripe. Stripe gestiona el procesamiento seguro de pagos para TocaToca.

Introduzca la información requerida, incluidos sus datos de pago.

![Stripe](/images/manual/stripe.jpg)

Si cancela su suscripción dentro de los tres días posteriores al registro, no se realizará ningún cargo.

## Activación

Cuando el registro y el pago se hayan completado correctamente, su cuenta se activará automáticamente.

Después podrá iniciar sesión en TocaToca y empezar a escuchar de inmediato.
