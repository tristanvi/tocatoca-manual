---
title: Navegador de escritorio
description: Usar TocaToca cómodamente en su ordenador.
---

TocaToca funciona directamente en su navegador web. No se necesita instalar software adicional ni ninguna aplicación.

## Abrir TocaToca

Vaya a [play.tocatoca.com](https://play.tocatoca.com).

Si aún no ha iniciado sesión, se le redirigirá automáticamente a la página de inicio de sesión.

## Ventajas de usar un ordenador

Usar TocaToca en un ordenador ofrece más espacio en pantalla para explorar el catálogo y descubrir música.

Una pantalla más grande facilita:

* recorrer colecciones
* comparar grabaciones
* trabajar con playlists
* explorar artistas, orquestas y grabaciones relacionadas

## Navegadores recomendados

TocaToca funciona con todos los navegadores modernos. Para una mejor experiencia, recomendamos:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox
* Safari

## Mantener el navegador actualizado

Recomendamos usar la versión más reciente de su navegador.

Esto garantiza una reproducción fiable, mayor seguridad y el mejor rendimiento posible al usar TocaToca.
