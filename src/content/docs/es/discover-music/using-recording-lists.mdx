---
title: Usar listas de grabaciones
description: Recorrer, explorar y reproducir grabaciones.
---

Las listas de grabaciones son una de las vistas más importantes de TocaToca. Aparecen en todo el catálogo, incluidos los resultados de búsqueda, las colecciones, los favoritos, las playlists y las páginas de artistas.

Aquí encontrará las grabaciones disponibles y podrá empezar a escuchar.

## Iniciar una grabación

Haga clic en una grabación o pulse el botón Play para empezar la reproducción.

La reproducción comienza de inmediato y el reproductor muestra la grabación que está sonando.

## Información sobre una grabación

Las listas de grabaciones contienen distintos datos, entre ellos:

* título
* artista
* orquesta
* cantante
* género
* año
* colección

Estos detalles le ayudan a descubrir más grabaciones en todo el catálogo.

## Usar información enlazada

Muchos elementos dentro de una lista de grabaciones son clicables.

Por ejemplo, al hacer clic en un cantante, una orquesta o un género se muestran todas las grabaciones disponibles asociadas a ese elemento.

Así puede explorar el catálogo paso a paso y descubrir nuevas conexiones musicales.

## Seleccionar varias grabaciones

Puede seleccionar varias grabaciones usando las casillas situadas junto a cada entrada.

Las grabaciones seleccionadas pueden:

* añadirse a una playlist
* reproducirse juntas
* gestionarse como grupo

Esto facilita crear sus propias colecciones y guardar grabaciones interesantes para escucharlas más tarde.
