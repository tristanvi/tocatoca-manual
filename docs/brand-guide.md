TocaToca Design Principles

Personality:
- warm
- elegant
- musical
- historical
- premium
- approachable

Avoid:
- corporate SaaS look
- developer documentation look
- cold technical styling

Visual anchors:
- Vixelle
- shellac era
- warm tones
- TangoTunes heritage
- listening experience

The cat Vixelle – 5th-Vixelle.png – is our main brand character next to the logo – mainlogo-v3.svg
We shall not use her excessively but to support in the following way.
To stress certain text blocks, to highlight them, to support an info box.

Introduce Vixelle as a recurring help character.

Create:
- custom homepage hero
- custom footer
- custom accent colors
- custom callout styles

Use Vixelle sparingly.

Good locations:
- homepage hero
- FAQ
- help callouts
- troubleshooting pages
- getting started pages

Avoid:
- every page header
- every information box
- repeated use on the same page

Maximum:
1 Vixelle illustration per page unless explicitly justified.

The manual should feel like part of TocaToca, not like a generic Starlight installation.

Do not change content.
Only improve visual design.
